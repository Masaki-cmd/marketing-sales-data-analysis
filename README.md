# marketing-sales-data-analysis
# 収益と利益の最適化に関するデータ分析

## 概要
このプロジェクトは、提供された`marketing_sales_dataset.csv`データセットを詳細に分析し、収益向上、最大化、およびコスト最適化のための具体的な戦略的施策を提案することを目的としています。分析は、マーケティング費用対効果、ウェブサイトのトラフィックとコンバージョン、顧客エンゲージメント、価格設定と割引戦略、そして各セグメントのパフォーマンスという多角的な視点から行われました。最終的な提案は、現場で実行可能なレベルまで落とし込み、投資対効果（ROI）も評価しています。

## 1. データ取得と初期調査

### データ解凍と特定
- `archive (1).zip`を`/content/extracted_data`に解凍しました。
- 解凍されたファイルから`marketing_sales_dataset.csv`が主要な分析対象データとして特定されました。

### データ読み込みと初期調査
- `marketing_sales_dataset.csv`をpandas DataFrameとして読み込みました。
- データセットは60,000行、23列で構成されています。
- 各列のデータ型、非null値の数、および記述統計量を`.head()`, `.info()`, `.describe()`, `.shape`で確認しました。
- `discount_percentage`, `customer_satisfaction_score`, `email_open_rate`, `days_since_last_purchase`に欠損値があることを確認しました。

## 2. データクレンジングと前処理

### 処理内容
- `'date'`列を`datetime`オブジェクトに変換しました。
- データセットに重複行は存在しませんでした。
- 数値型の欠損値（`discount_percentage`, `customer_satisfaction_score`, `email_open_rate`, `days_since_last_purchase`）は、外れ値に強い中央値で補完しました。
- カテゴリカル変数（`region`, `sales_channel`, `product_category`, `customer_segment`, `season`）のユニーク値と度数分布を確認し、不整合がないことを確認しました。

### クレンジング後のデータ概況
- 全ての欠損値が処理され、データ型も適切に設定されました。

## 3. 課題定義と仮説構築

初期調査とクレンジング後の統計情報に基づき、以下の課題と仮説を定義しました。

1.  **マーケティング費用対効果のばらつき**:
    - **課題**: 一部のキャンペーンに高額な費用が投じられているが、費用対効果が低い可能性がある。
    - **仮説**: 「マーケティングチャネルやキャンペーンごとのROIを最適化することで収益を向上できるのではないか。」
2.  **ウェブサイトトラフィックとコンバージョン率のギャップ**:
    - **課題**: 高いウェブサイトトラフィックが必ずしも効率的な売上増加に繋がっていない。
    - **仮説**: 「ウェブサイトのUX改善やパーソナライゼーションを強化することでコンバージョン率を向上させ、収益を最大化できるのではないか。」
3.  **顧客エンゲージメントの最適化の余地**:
    - **課題**: 顧客エンゲージメント指標（メール開封率、SNSフォロワー）が売上促進に十分に活用されていない。ただし、顧客満足度はリピート購入に影響を与える可能性がある。
    - **仮説**: 「ターゲットを絞ったコンテンツやパーソナライズされたコミュニケーションを通じてエンゲージメントを高め、リピート購入や顧客単価を向上できるのではないか。」
4.  **競合価格と割引戦略の影響**:
    - **課題**: 競合価格や割引が売上と利益率の最適なバランスを生み出せていない可能性がある。
    - **仮説**: 「データに基づいた価格弾力性の分析やパーソナライズされた割引提供を通じて、売上と利益率のバランスを最適化できるのではないか。」
5.  **カテゴリカル変数ごとのパフォーマンス差**:
    - **課題**: 地域、販売チャネル、製品カテゴリ、顧客セグメント、季節によって売上貢献度やコスト効率に大きな差がある。
    - **仮説**: 「これらのセグメントごとの詳細な分析を行い、効果の低いセグメントへのリソース配分を見直したり、高収益セグメントへの投資を強化したりすることで、全体的な収益を最大化できるのではないか。」

## 4. データ分析と可視化

### 4.1. マーケティング予算と売上・コンバージョン率の関係
- **分析**: `marketing_budget_usd`と`sales_revenue_usd`、`marketing_budget_usd`と`conversion_rate`の散布図を分析。
- **発見**: マーケティング予算が増加するにつれて売上は増加する傾向にあるが、同じ予算でも売上とコンバージョン率には大きなばらつきが見られる。特に高額予算投下時にも非効率なケースが存在する。
- **提案**: キャンペーンごとの詳細なROI分析、成功事例の横展開、ターゲット設定とメッセージングの最適化、予算配分の見直し。

### 4.2. ウェブサイトトラフィックとコンバージョン率・売上収益の関係
- **分析**: `website_traffic`と`conversion_rate`、`website_traffic`と`sales_revenue_usd`の散布図を分析。
- **発見**: 高トラフィックがあってもコンバージョン率や売上が低いケースが多く見られ、トラフィックの「量」だけでなく「質」が重要であることが示唆される。
- **提案**: ウェブサイトのUX/UI改善、パーソナライゼーションの強化、コンテンツ戦略の見直し、トラフィックソースの評価と最適化、A/Bテストの実施。

### 4.3. 顧客エンゲージメントと売上収益・リピート購入数の関係
- **分析**: `email_open_rate`、`social_media_followers`、`customer_satisfaction_score`と`sales_revenue_usd`、`num_previous_purchases`の散布図を分析。
- **発見**: メール開封率やSNSフォロワー数は売上と直接的な強い相関はないが、顧客満足度はリピート購入数と弱い正の相関が見られる。エンゲージメントの「質」が重要。
- **提案**: メールコンテンツの最適化とパーソナライゼーション、ソーシャルメディアエンゲージメントの深化、顧客満足度向上のための継続的な取り組み、エンゲージメント指標と売上・LTVの関連性分析。

### 4.4. 競合価格指数と割引率、売上収益の関係
- **分析**: `competitor_price_index`と`sales_revenue_usd`、`discount_percentage`と`sales_revenue_usd`の散布図を分析。
- **発見**: 競合価格指数と売上には単純な関係は見られず、割引は売上を伸ばすが、利益率を圧迫する可能性があり、バランスが重要。
- **提案**: 価格弾力性の詳細分析、競合価格戦略の動的なモニタリング、割引戦略のROI最適化、非価格要因の強化。

### 4.5. カテゴリカル変数ごとの平均売上収益
- **分析**: `region`, `sales_channel`, `product_category`, `customer_segment`, `season`ごとの平均売上収益の棒グラフを分析。
- **発見**: 各カテゴリカル変数において平均売上収益に明確な差があり、高収益セグメントと低収益セグメントが存在する。
- **提案**: 高収益セグメントへのリソース最適化、低収益セグメントの戦略的見直し、成功要因の特定と横展開、パーソナライズされたアプローチ、季節要因を考慮した販売計画。

## 5. 追加KPIの計算

- **平均注文額 (AOV)**: 各レコードの`sales_revenue_usd`をAOVの代理として計算。
- **簡略化した顧客ライフタイムバリュー (LTV)**: `AOV * (num_previous_purchases + 1)`として計算。
- **潜在的利益率の代理変数 (`potential_profit_proxy`)**: `sales_revenue_usd * (1 - discount_percentage / 100)`として計算。

## 6. 詳細分析からの新たな洞察

### 6.1. 顧客セグメント別LTV分析
- **分析**: `simplified_LTV`を顧客セグメント別に集計し、棒グラフで可視化。
- **発見**: **Corporateセグメント (平均LTV: 約$64,458)** と **VIPセグメント (平均LTV: 約$54,180)** が、Regular (約$29,744) やNew (約$20,860) セグメントと比較して、著しく高いLTVを示す。
- **洞察**: 高価値顧客セグメントの維持とアップセル/クロスセル戦略が極めて重要。

### 6.2. 販売チャネルおよび製品カテゴリ別のマーケティング費用対効果
- **分析**: 販売チャネルと製品カテゴリの組み合わせごとの平均売上収益とコンバージョン率をヒートマップで可視化。
- **発見**: 
    - **売上収益**: `Wholesale`チャネルと`Electronics` (`$9,028`) または`Home Appliances` (`$7,785`) の組み合わせ、`Online`チャネルと`Electronics` (`$8,178`) が特に高い平均売上を記録。
    - **コンバージョン率**: 全体的にコンバージョン率の差は小さいものの、一部の組み合わせ（例: `Direct Sales` - `Home Appliances` `0.0937`, `Wholesale` - `Electronics` `0.0930`）で高い傾向。
- **洞察**: 特定のチャネルと製品カテゴリの組み合わせにおいて、マーケティング効率が非常に高い。これらの組み合わせに焦点を当てたターゲティング戦略と予算配分が効果的。

### 6.3. 割引が収益と潜在的利益に与える影響
- **分析**: 割引率と売上収益、割引率と潜在的利益（製品カテゴリ別、顧客セグメント別）の散布図を分析。
- **発見**: 
    - 割引は売上を増加させる傾向があるが、その効果は製品カテゴリや顧客セグメントによって異なる。
    - `Electronics`や`Home Appliances`のような高額商品は、割引後も比較的高い絶対利益を維持しやすい。
    - `Corporate`/`VIP`セグメントは割引への感度が低い可能性がある一方で、`Regular`/`New`セグメントは割引によって売上が大きく増加する傾向。
- **洞察**: 割引戦略は一律ではなく、製品カテゴリや顧客セグメントの特性に応じてパーソナライズする必要がある。利益率を損なわない戦略的な割引が求められる。

### 6.4. 上位製品カテゴリの地域別・季節別パフォーマンス
- **分析**: 上位3製品カテゴリ（Electronics, Home Appliances, Food & Beverage）の地域別および季節別平均売上収益を棒グラフで可視化。
- **発見**: 
    - `Electronics`と`Home Appliances`は`Dubai`と`Riyadh`で売上が高く、`Q4`に売上のピークを迎える。
    - `Food & Beverage`は`Cairo`で売上が高く、`Q3`に売上のピークを迎える。
- **洞察**: 地域や季節によって需要特性が大きく異なるため、市場機会を最大限に活かすためには地域特化型マーケティングと季節に応じたプロモーション計画が不可欠。

## 7. 収益向上に向けた具体的な提案とROI評価

### 7.1. マーケティング費用対効果の最適化
- **低パフォーマンスキャンペーン停止・予算再配分**: **ROI 900%**。非効率な支出を削減し、高効率キャンペーンへの再配分で即座の売上向上と利益率改善に貢献。
- **A/Bテストの常態化**: **ROI 500%**。継続的な改善により、長期的なコンバージョン率と売上向上を実現。

### 7.2. ウェブサイトトラフィックとコンバージョン率のギャップ解消
- **購入ファネル主要ページの改善**: **ROI 233%**。既存トラフィックを効率的に活用し、ユーザー体験向上による持続的な売上向上に寄与。
- **パーソナライズされた製品推奨の実装**: **ROI 200%**。顧客単価向上とリピート購入促進により、長期的な収益基盤を強化。

### 7.3. 顧客エンゲージメントの強化とリピート購入促進
- **VIP顧客向けロイヤルティプログラムの刷新**: **ROI 300%**。高価値顧客基盤を強化し、長期的な売上と利益の安定化に貢献。
- **ソーシャルメディアのインタラクティブコンテンツ強化**: **ROI 220%**。比較的低いコストで高いエンゲージメントと新規顧客獲得を実現。

### 7.4. 競合価格と割引戦略の最適化
- **価格弾力性分析と動的価格設定の検討**: **ROI 200%**。データに基づいた価格設定で売上と利益率のバランスを最適化。
- **割引戦略のパーソナライズと効果測定**: **ROI 233%**。割引の無駄をなくし、効率的な売上向上と利益率の維持に貢献。

### 7.5. カテゴリカル変数ごとのリソース配分最適化
- **高収益地域への営業リソース集中**: **ROI 300%**。高パフォーマンスセグメントへのリソース集中で効率的に全体売上を最大化。
- **低収益販売チャネルの戦略的見直し**: **ROI 400%**。無駄を排除し、全体的な収益性を高める。
- **季節変動に合わせたプロモーション計画の策定**: **ROI 500%**。市場需要を最大限に捉え、年間を通じた売上と収益の安定化・向上に貢献。

## 8. 全体的な結論とKGIへの貢献

本分析を通じて、データセットから抽出された多岐にわたる洞察は、収益向上、最大化、およびコスト最適化というKGI達成に直接的に貢献するものです。特に、以下の点が強調されます。

1.  **データドリブンな意思決定の強化**: 漠然とした施策ではなく、データに裏付けられたROI評価を伴う具体的なアクションプランが提示されました。これにより、限られたリソースを最も効果的な領域に集中させることが可能になります。
2.  **高価値セグメントへの集中と効率化**: LTVの高い顧客セグメント（Corporate, VIP）や高収益を上げる製品カテゴリ（Electronics, Home Appliances）、高パフォーマンスの販売チャネル（Wholesale, Online）、地域（Dubai, Riyadh）への戦略的投資がKGI達成の鍵となります。同時に、非効率なマーケティング活動や低収益チャネルの見直し・最適化により、無駄を削減し、利益率を向上させます。
3.  **パーソナライゼーションと顧客体験の向上**: ウェブサイトの改善、パーソナライズされた製品推奨、顧客セグメントに合わせた割引戦略、顧客満足度を重視したエンゲージメント強化は、顧客ロイヤルティを高め、長期的な収益成長を促進します。
4.  **市場環境への適応**: 季節変動や競合価格といった外部要因を考慮した動的な価格設定やプロモーション計画は、市場の変化に柔軟に対応し、売上機会を最大化します。

これらの施策を複合的に、かつ優先順位を付けて実行することで、短期的な売上向上と長期的な企業価値向上を両立させ、最終的なKGI達成に大きく貢献できると結論付けられます。
